# R Chandak & Associates | Official Firm Web Portal

A modern, responsive, single-page web application for **R Chandak & Associates**, a Hyderabad-based Chartered Accountancy firm specializing in Audit, Direct & Indirect Taxation, FEMA & NRI Advisory, Virtual CFO Services, and Real Estate Advisory.

---

## 🌟 Key Features

* **Regulatory Compliance**: Includes an interactive ICAI Ethics Disclaimer modal compliant with ICAI website disclosure guidelines.
* **Live Financial Benchmarks**: Real-time streaming ticker powered by TradingView for major equity indices (NIFTY 50, SENSEX, BANK NIFTY), commodities (Gold, Silver), and Forex (USD/INR).
* **Exhaustive TDS/TCS Engine**: Full calculation engine updated with the statutory framework of the **Income Tax Act, 2025** (Sections 392 & 393 with official payment codes 1001–1067).
* **Financial Calculator Suite**: On-site calculators for GST, Income Tax (New Tax Regime), Capital Gains, and SIP Wealth creation.
* **On-Site Circular Reader**: Embedded statutory updates feed allowing visitors to read full CBDT, CBIC, and RBI notifications on-site.
* **Leadership & Thought Leadership**: Integrated bios for leadership and linked updates to the official firm LinkedIn page.

---

## 🛠️ Tech Stack & Dependencies

* **HTML5 & Vanilla JavaScript (ES6+)**: Zero external JavaScript framework overhead.
* **Tailwind CSS**: Styled using the Tailwind CSS CDN for utility-first responsive design.
* **TradingView Ticker Widget**: Embedded for live market data feed.
* **Asset Dependencies**:
  * `Picture3.jpg` (Firm Logo Asset)
  * `Rajat.png` (Leadership Portrait)
  * `Harsikha.png` (Leadership Portrait)
